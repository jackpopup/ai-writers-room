# Direction Brief: 유튜브 데이터 자동 수집 영상

## 합의된 방향

### 워킹 타이틀 (Top 3)

1. **"Claude Code로 유튜브 분석 자동화했습니다 — 삽질 5일의 기록"** (기자 추천)
2. **"API가 거절당한 순간, 진짜 자동화가 시작됐다"** (PD 추천)
3. **"유튜브 분석, AI가 매일 알아서 해줍니다"** (카피라이터 추천)

### 핵심 메시지 (1문장)

> AI 코딩의 진짜 실력은 코드를 짜는 순간이 아니라 벽에 부딪혔을 때 드러나며, "왜 이렇게 했는지"를 아는 것이 "어떻게 했는지"보다 중요하다.

### 타겟 시청자

- **주 시청자**: 유튜브 채널 운영하면서 데이터를 수작업으로 스프레드시트에 옮기고 있는 마케터/운영자. 자동화하고 싶지만 코딩을 모르니 엄두를 못 내는 사람.
- **부 시청자**: AI 활용법을 찾는 탐색자. Claude Code, ChatGPT를 써봤지만 "진짜 업무에 쓸 만한 사례"를 못 찾은 사람.

### 톤 방향

**"옆자리 선배가 실패담까지 솔직하게 알려주는 회고"**

- 강의 톤 X, 회고 톤 O
- 삽질을 숨기지 않는 투명함 (신뢰 구축)
- 기술 용어 쓰되 반드시 1문장 설명 동반
- "나도 해볼 수 있겠다"는 현실적 자신감 부여

### 차별점 — 왜 이 영상이 가치 있는가

| 기존 AI 자동화 영상 | 이 영상 |
|---|---|
| 결과물만 보여주는 쇼케이스 | 기획 → 삽질 → 피벗 → 완성 전체 여정 |
| "이렇게 하면 됩니다" | "이렇게 했더니 안 됐고, 그래서 이렇게 바꿨다" |
| 코드 복붙 튜토리얼 | 의사결정 과정 + 사고방식 전달 |
| 성공만 보여줌 | 구현 과정의 의사결정과 시행착오를 함께 보여줌 |

### 시청자가 영상 후 가져가는 것

코드가 아니라 **"AI와 협업해서 자기 업무를 자동화하는 사고방식"**

## 4인 에이전트 핵심 의견 요약

### 기자 (시니어 저널리스트)
- **앵글**: "AI 코딩 튜토리얼의 99%는 되는 것만 보여준다. 이건 안 된 것을 보여준다."
- **훅 제안**: "이 시스템을 만드는 데 5일 걸렸습니다. 코드를 짠 건 Claude가 했고, 제가 한 건 — 세 번 방향을 바꾼 겁니다."
- **핵심**: 세션 4의 위기(Analytics API Forbidden)가 영상의 클라이맥스

### 카피라이터
- **앵글**: 완성된 결과물이 아니라 "AI와 함께 문제를 풀어가는 과정"이 콘텐츠
- **훅 보강**: "자동화 '된다'는 건 누구나 안다. 문제는 중간에 5번은 망한다는 것"
- **핵심**: 시청자 감정 → "나도 이렇게 하면 되겠구나. 실패해도 괜찮구나."

### PD (프로듀서)
- **스토리 아크**: 흥분 → 자신감 → 위기 → 우회 → 해결 → 새로운 함정 → 최종 완성
- **감정의 최저점(Session 4)이 이 영상의 심장**
- **핵심**: 위기가 두 번 온다 — 시청자는 "또?"라고 반응하면서 더 몰입

### 편집자
- **구조 개선**: 본론 2(7분)를 설계/구축으로 분리하여 리듬 개선
- **WHY 분산**: 기획에만 집중하지 말고 모든 본론에 "핵심 WHY" 배치
- **훅 개선**: 완성물을 먼저 보여주고 → 충격("코드 한 줄 안 씀") → 기대감("과정에서 배운 것이 중요")
